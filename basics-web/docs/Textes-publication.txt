DESCRIPTION (EN)
Visitors don't read. They scan. 5 UI/UX basics for any website:
1. One clear headline: say what you do.
2. One main button per screen.
3. Visual hierarchy: size, weight and contrast.
4. Consistent spacing: 8, 16, 24, 32.
5. Readable text: shorter lines, stronger contrast.
The interface in this video is fictional.
Follow for more UI/UX tutorials.
