DESCRIPTION (EN)
Too many borders and shadows. 5 basics to fix it:
1. Space, not lines: Group with spacing and a soft background.
2. Soft shadows: Blurred, light and slightly below.
3. Two or three levels: Higher elements cast bigger shadows.
4. One corner radius: Pick one radius and reuse it.
5. Nested radius: Inner radius = outer radius − padding.
The interface in this video is fictional.
Follow for more UI/UX tutorials.

DESCRIPTION (AR)
حدود وظلال كثيرة جدًا. 5 أساسيات لإصلاح ذلك:
1. مسافات بدل الخطوط: جمّع بالمسافات وخلفية خفيفة.
2. ظلال ناعمة: ضبابية وخفيفة ومنخفضة قليلًا.
3. مستويان أو ثلاثة: العناصر الأعلى تُلقي ظلالًا أكبر.
4. تدوير زوايا موحّد: اختر قيمة تدوير واحدة وأعد استخدامها.
5. تدوير متداخل: التدوير الداخلي = الخارجي − الحشو.
