FOR UX
- HTML: structure and accessibility.
- CSS: spacing, layout, responsive.
- JavaScript basics: loading, error and success states.
- SwiftUI or Compose: native app components.
- Python: surveys and A/B tests.

FOR UI
- Web: HTML + CSS.
- Interactive web: JavaScript or TypeScript + React.
- iPhone: Swift with SwiftUI.
- Android: Kotlin with Jetpack Compose.
- Both mobiles: Dart with Flutter.

Start with CSS. Then pick a platform.
Follow for more UI/UX tutorials.

DESCRIPTION (AR)
المصمم ليس مضطرًا للبرمجة، لكن بعض اللغات تجعلك أفضل في تجربة المستخدم، وبعضها يبني الواجهة نفسها.

لتجربة المستخدم
- HTML: الهيكل وإمكانية الوصول.
- CSS: المسافات والتخطيط والتجاوب.
- أساسيات JavaScript: حالات التحميل والخطأ والنجاح.
- SwiftUI أو Compose: مكوّنات التطبيقات الأصلية.
- Python: الاستبيانات واختبارات A/B.

لبناء الواجهات
- الويب: HTML وCSS.
- الويب التفاعلي: JavaScript أو TypeScript مع React.
- iPhone: لغة Swift مع SwiftUI.
- Android: لغة Kotlin مع Jetpack Compose.
- الاثنان معًا: لغة Dart مع Flutter.
