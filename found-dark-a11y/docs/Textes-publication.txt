Dark Mode & Accessibility Basics | أساسيات الوضع الداكن وإمكانية الوصول

DESCRIPTION (EN)
Can everyone read this? 5 basics to fix it:
1. Enough contrast: Dim text on black fails WCAG AA.
2. Never color alone: Add an icon or a word to every status.
3. Visible focus: Show which field is active.
4. Dark gray, not black: Surfaces show depth on dark gray.
5. Softer colors: Neon colors glare on dark backgrounds.
The interface in this video is fictional.
Follow for more UI/UX tutorials.

DESCRIPTION (AR)
هل يستطيع الجميع قراءة هذا؟ 5 أساسيات لإصلاح ذلك:
1. تباين كافٍ: النص الباهت على الأسود لا يجتاز WCAG AA.
2. لا تعتمد على اللون وحده: أضف أيقونة أو كلمة لكل حالة.
3. تركيز ظاهر: أظهر الحقل النشط بوضوح.
4. رمادي داكن لا أسود: الأسطح تُظهر العمق على خلفية رمادية داكنة.
5. ألوان أهدأ: الألوان الفاقعة تُبهر العين على الخلفيات الداكنة.
