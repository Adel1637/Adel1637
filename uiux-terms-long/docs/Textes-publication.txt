DESCRIPTION (EN + AR)
==================================================================
The words designers and developers use every day, shown on real-looking interfaces. UI elements: navigation (navbar, sidebar, breadcrumb, search bar, tabs, pagination), content (hero, CTA, card grid, carousel, accordion, footer), forms (text field, error message, select, checkbox, radio button, toggle, slider), actions and status (buttons, ghost button, badge, chip, avatar, progress bar, table), overlays and feedback (tooltip vs popover, modal, drawer, toast, skeleton) and mobile (tab bar, hamburger menu, FAB, bottom sheet, segmented control). Then 10 UX concepts: wireframe, mockup and prototype, affordance vs signifier, user flow vs user journey, persona, information architecture, Fitts's law, Hick's law, Jakob's law, usability test and A/B test.

الكلمات التي يستخدمها المصممون والمطوّرون كل يوم، معروضة على واجهات واقعية. عناصر الواجهة: التنقل (شريط التنقل، والشريط الجانبي، ومسار التنقل، وشريط البحث، وعلامات التبويب، وترقيم الصفحات)، والمحتوى (القسم الرئيسي، وزر الدعوة إلى الإجراء، وشبكة البطاقات، والعرض الدوّار، والقائمة القابلة للطي، والتذييل)، والنماذج (حقل الإدخال، ورسالة الخطأ، والقائمة المنسدلة، ومربع الاختيار، وزر الاختيار الواحد، ومفتاح التبديل، وشريط التمرير)، والإجراءات والحالات، والطبقات والتنبيهات، والهاتف. ثم عشرة مفاهيم في تجربة المستخدم، مع نصيحة عملية لكل مفهوم.
