Icons & Images Basics for UI | أساسيات الأيقونات والصور

DESCRIPTION (EN)
Your icons don't match. 5 basics to fix it:
1. One icon family: All outline or all filled, never mixed.
2. Same stroke weight: One stroke width for every icon.
3. Label unclear icons: An icon alone can be misread.
4. Overlay behind text: Text on photos needs a dark gradient.
5. Consistent image ratios: One ratio, cropped to fit.
The interface in this video is fictional.
Follow for more UI/UX tutorials.

DESCRIPTION (AR)
أيقوناتك غير متناسقة. 5 أساسيات لإصلاح ذلك:
1. عائلة أيقونات واحدة: كلها محدّدة أو كلها ممتلئة، دون خلط.
2. سُمك خط موحّد: سُمك خط واحد لكل الأيقونات.
3. أضف نصًا للأيقونات الغامضة: الأيقونة وحدها قد تُفهم خطأ.
4. طبقة داكنة خلف النص: النص فوق الصور يحتاج تدرّجًا داكنًا.
5. نِسب صور موحّدة: نسبة واحدة مع قصّ مناسب.
