DESCRIPTION (EN)
6 free resources to start learning UI/UX, in the right order:

1. Laws of UX — the psychology behind good interfaces
   lawsofux.com
2. Nielsen Norman Group — UX rules backed by research
   nngroup.com/articles
3. Material Design 3 — Google's design system for Android and web
   m3.material.io
4. Apple Human Interface Guidelines — Apple's official rules for iPhone apps
   developer.apple.com/design/human-interface-guidelines
5. WebAIM Contrast Checker — check if your text is easy to read
   webaim.org/resources/contrastchecker
6. Figma — the design tool, free to start
   figma.com

Not sponsored. Save this list for later.
Follow for more UI/UX tutorials.
